# 💼 Sumaiya — Developer Portfolio

A modern, responsive portfolio built with **HTML**, **CSS** and **vanilla JavaScript** to showcase my projects, skills and journey towards becoming a MERN stack developer.

## 🌐 Live Demo
[sumaiya7286.github.io/Portfolio-website](https://sumaiya7286.github.io/Portfolio-website/)

## ✨ Features
- Glassmorphism UI with animated gradient background
- Typing effect in the hero section
- Sticky navbar with active-section highlighting
- Scroll-reveal animations and animated counters
- Experience timeline and skill cards
- Project cards with live demo + source links
- Contact form (opens the visitor's email app)
- Fully responsive with a slide-in mobile menu
- Respects "reduce motion" accessibility settings

## 🛠️ Tech Used
HTML5 · CSS3 · JavaScript (ES6) · Font Awesome · Google Fonts (Poppins)

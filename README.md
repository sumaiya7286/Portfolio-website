# 💼 Sumaiya — Developer Portfolio

A modern, responsive portfolio built with **HTML**, **CSS** and **vanilla JavaScript** to showcase my work, skills and journey towards becoming a MERN stack developer.

## 🌐 Live Site
[sumaiya7286.github.io/Portfolio-website](https://sumaiya7286.github.io/Portfolio-website/)

## ✨ Features
- Glassmorphism UI with an animated gradient background
- Floating glass navbar with active-section highlighting
- Typing effect in the hero section
- Scroll-reveal animations and animated counters
- Experience timeline and skill cards
- Featured project card with live demo and source links
- Contact form that opens the visitor's email app
- Fully responsive with a slide-in mobile menu
- Respects "reduce motion" accessibility settings

## 🛠️ Tech Used
HTML5 · CSS3 · JavaScript (ES6) · Font Awesome · Google Fonts (Poppins)

## 📁 Featured Project
**🔖 Stash — every link worth keeping**
A full-stack app to save, organise and search the videos, docs and articles you want to come back to, synced across devices.
Built with Next.js, React, TypeScript, Tailwind CSS and Supabase.
